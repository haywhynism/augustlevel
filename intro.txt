Variable Declarations

const - constant variable whose value can never change

Arithmetic Operators
+ (Addition)
- (Subtraction)
/ (Division)
* (Multiplication)
% (Modulus - remainder) 19 % 4 = 3
= (Equal to)

Unary Operators
++ (increment by 1)
let a = 5
a++ (a = 6)
-- (decrement by 1)
let b = 4
b-- (b = 3)

Binary Operators
+= 
a = 5
b = 6
a += b (whatever a was before, add b to it a = 11)
-= 
a = 10
b = 6
a -= b (whatever a was before, add b to it a = 4)

Tenary Operators
a = 20
a == 5 ? a : 7 (if a is 5 return a else return 7)
